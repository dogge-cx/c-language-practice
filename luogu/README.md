## 刷题心得

- **卡住超过 20 分钟就看题解**。看懂思路 → 关掉 → 自己默写一遍，这比死磕一晚上有用。
- 每道题都要 **AC（全部测试点通过）**，不要"样例过了就跑"。
- 做错的题记到 `../notes/` 里的错题本。
- 每题提交后顺手 commit：
  ```bash
  git add .
  git commit -m "洛谷 B2001 入门测试题目"
  git push
  ```
